Feature You can create a VPC network that supports RDMA over Falcon transport , which lets you run AI and high performance computing (HPC) workloads on VM instances that have the IRDMA network interface type in Google Cloud, such as H4D instances. This feature is available in Preview . For more information, see RDMA network profiles .
